# 🛍️ SmartTech Store Management System

A web application built with Python and Flask for managing electronic products and store inventory.

## 🔗 Live Demo
https://gangaprasadkadam.pythonanywhere.com/

## 📋 Features
- Product management (Add, Edit, Delete, View)
- Search products by name, category, or price
- Filter products by category and stock status
- User registration and login
- Admin panel — only admins can add, edit, or delete products
- Inventory management with stock tracking
- Responsive design — works on mobile and desktop

## 🛠️ Tech Stack
Backend: Python, Flask
Database: SQLite
Frontend: HTML, Bootstrap 5, JavaScript
Deployment: PythonAnywhere
