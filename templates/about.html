🛒 About Shop Inventory System

# The Shop Inventory System is a simple inventory management web application developed using Python Flask and Bootstrap 5.

# It helps shop owners manage products,stock quantity, prices, and categories in an organized way.

🎯 Project Objective

# The main objective of this project is to provide an easy and user-friendly system for managing shop inventory efficiently.

# It reduces manual work and keeps product information organized.

✨ Features

  • 🏠 Home Dashboard
  • 📦 View All Products
  • ➕ Add New Product
  • ✏️ Edit Product
  • 🗑️ Delete Product
  • 🔍 Search Products
  • 📂 Filter Products by Category
  • 📄 Product Details
  • 💬 Flash Messages
  • 📱 Responsive Bootstrap Design
  • ⚠️ Custom 404 Error Page

💻 Technologies Used

Frontend HTML5, CSS3, Bootstrap 5, Jinja2
Backend Python Flask
Database SQLite3
Programming Language Python
IDE Visual Studio Code

  • Inventory Management
